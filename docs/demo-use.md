# Demo use

## Purpose and limits

These are instructional lab examples, not a production service. Use only the synthetic fixtures or other non-sensitive test data. Review every generated draft; the skill does not send messages, schedule events, or authorize actions.

## Privacy

The canonical skill contains instructions only, with no external service calls or repository-operated data collection endpoint. The selected Microsoft or GitHub host processes prompts, skill content, outputs, and diagnostic data under that host's terms, configuration, retention, and administrator policies. Deployment scripts store skill content in the selected cloud project; test requests may incur model or Copilot Credit charges.

Do not submit personal, confidential, or customer data to these demonstrations. Keep tenant configuration, credentials, and detailed lab evidence outside the public repository. These notes describe the examples; they are not a substitute for an organization's production privacy notice.

## Demo terms

Use the examples for evaluation in an authorized lab. Validate generated output and platform compatibility independently.
